# Project template
## Question to think about

1. What inspired you to build this project?
2. What were the challenge you faced when making this project?
3. What did you learn from making this project?
4. How did what you leaned impact other projects?
5. What would you do differently?
6. Did you get stuck at any point? How did you get unstuck?
7. WHat was your process and the tools used for this project?
8. What were your assumptions?

## Ways to illustrate warning

1. Create an architecture diagram of your application
2. Show your kangan borads and road maps to illustrate how you break down storeis and manage projects
3. Explore different perspectives of problem-solving and diagram them
4. Take photos of your notes and sketches

## What employers want to see

1. Write, document and test code
2. Work professionally
3. Communicate problems, ideate
4. Work on a team
5. Work quickly and eagerly
6. Collaborate and potentially lead 

## What types of projects should you include?

1. Well-designed UI mock-ups or code
2. Show how you use APIS and how you manage large amount of data
3. Architectural diagrams and system design documents
4. Write automated test for your code
5. If you use a tutorial to complete a project, call it out - or better yest, go beyond the tutorial and make it your own

## Code in Github

1. Write a clean and informative README
2. Use a linter to ensure consistent code formatting
3. Document your code thoourgh comments
4. Write automated test
